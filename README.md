# BRO.TEIN Sport Nutrition Platform

> Personalized nutrition, training, and F&B — automatically built around your goal.

## Overview

A premium sport nutrition + fitness + F&B management platform that automatically generates daily nutrition plans, training programs, and seamlessly connects to F&B ordering.

**Core Philosophy:** Less choice. Better personalization.

Customers answer a few questions → system automatically generates complete daily plans → mandatory Smoothie + Whey → daily tracking → progress insights.

## Quick Start

### Frontend

```bash
cd frontend
npm install
npm run dev
# Opens at http://localhost:5173
```

### Backend

```bash
cd backend
npm install
npm run dev
# Runs at http://localhost:3000
```

### Database

```bash
docker-compose up
# PostgreSQL at localhost:5432
```

## Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, Recharts
- **Backend:** Node.js, Express, Prisma ORM
- **Database:** PostgreSQL
- **Authentication:** JWT
